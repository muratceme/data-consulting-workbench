NASIL ÇALIŞIR?

Danışmanlık işini bir pakete dönüştür.

01

Alan → yazılım → ürün → görev

23 ana veri alanı ve ürün bağlamları arasında görevi bul. Katalog genişletilebilir; tüm dünyadaki yazılımların eksiksiz listesi değildir.

02

Doğru çalışma biçimini seç

Kod blokları sabit kurallarla yerelde çalışır. Aynı motor birden çok ürünün CSV çıktısıyla kullanılabilir. API paketleri access token ister. Agentlar OpenAI uyumlu API, Claude veya Ollama ile kanıtları yorumlar.

03

İndir, yapılandır, çalıştır

ZIP’i aç. README’deki komutu çalıştır. config.json içindeki alanları kendi verine göre düzenle. Agent için .env.example dosyasını .env olarak kopyala ve modelini seç. Önce --dry-run ile isteği incele.

04

Çıktıyı incele ve teslim et

Kodlar HTML / JSON / CSV / Markdown üretir. Agent çıktıları insan incelemesi gerektiren taslaklardır. Agentlar önerilen kodu veya üretim değişikliklerini otomatik yürütmez.
