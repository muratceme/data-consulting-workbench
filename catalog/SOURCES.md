# Katalog ve API kaynakları

İnceleme tarihi: 11 Ekim 2026. Katalog editoryal bir veri danışmanlığı taksonomisidir; popülerlik sıralaması ya da eksiksiz pazar listesi değildir. Ürün sürümleri ve erişilebilir modeller hesabınıza göre doğrulanmalıdır.

- Microsoft Fabric alanları: https://learn.microsoft.com/en-us/fabric/fundamentals/microsoft-fabric-overview
- SAP Data Services kapsamı: https://help.sap.com/docs/SAP_DATA_SERVICES
- BigQuery veri yönetişimi: https://docs.cloud.google.com/bigquery/docs/data-governance
- Logo ürün ailesi: https://www.logo.com.tr/en/logo-all-products-a-to-z (yerleşik GO / Tiger / Netsis bağlamları dahil)
- Qlik REST items envanteri: https://qlik.dev/apis/rest/items/
- Qlik apps: https://qlik.dev/apis/rest/apps/
- Power BI reports GET: https://learn.microsoft.com/en-us/rest/api/power-bi/reports/get-reports-in-group
- BigQuery tables.list: https://docs.cloud.google.com/bigquery/docs/reference/rest/v2/tables/list
- OpenAI Chat Completions: https://developers.openai.com/api/reference/resources/chat/subresources/completions/methods/create
- Claude Messages: https://platform.claude.com/docs/en/api/messages/create
- Ollama chat: https://docs.ollama.com/api/chat

Kaynaklar ürün alanlarını ve read-only API yollarını destekler. Diğer platformlar için katalogdaki CSV iş akışları ortak yerel motorları kullanır; bu platformlarda native API uyumluluğu iddia edilmez.
